# Backend dependencies. Deliberately few — everything else uses the Python
# standard library, including the database (SQLite).
#
# Nothing here contains compiled code, which is the point. The one dependency
# that did — h3, for the aggregate map's hexagons — has been replaced with a
# plain rectangular grid computed in Python. It teaches the same lesson: at a
# threshold of five, hexagons and the grid showed the same number of cells on
# the sample data. It was not worth being the only thing in the project that
# could fail to install, which on Android under Termux meant a tablet spending
# hours compiling a C++ build system before anybody reached the lesson.
