# The hexagon grid behind the k-anonymity aggregate map. The only dependency
# here containing compiled C, and therefore the only one that can fail to
# install.
#
# --only-binary matters more than it looks. Without it, a platform with no
# prebuilt wheel — Termux on Android being the real case — falls back to
# building from source, and h3's build wants CMake. If CMake is not installed
# either, pip fetches the `cmake` package from PyPI, which on that platform
# also has no wheel, and proceeds to compile the entire CMake C++ codebase.
# That is hours of build on a tablet, for a hexagon library, and it frequently
# fails or runs out of memory at the end anyway.
#
# With this line, such a platform fails in seconds with "no matching
# distribution", which is a thing somebody can read and act on. Everything
# except the aggregate map works without h3, and the dashboard says so on the
# one screen that needs it.
--only-binary=h3
h3==4.5.0
